# X-Treme-Boss-Engine-Restoration

A very amateur attempt at decompiling/restoring Christina Coffin's "Boss Engine", the final engine chosen for the infamously ill-fated mainline Sonic the Hedgehog game "Sonic X-Treme"


(This is likely a far more stripped down version of the engine than was available to the team before Sonic X-Treme's cancellation, as the only leaked build using this engine is the "718" build, also known as the "Jade Gully Demo" build. 
Do not expect much from this. This is a passion project done by a broke 20 year old college student. I barely know C and don't use AI to help/write any of my code, so progress will be slow!)

A little extra info:
- This engine was originally built to be used only for the game's boss fights. If you know anything about the disaster that was Sonic X-Treme, you'll probably recognize this engine from the Metal Sonic boss that was playable at E3 1996.

- After the debacle over the NiGHTS engine, Sega Technical Institute would fall back to the best looking and performing engine they had at the time, which was Christina's Boss engine. Unlike the PC builds of Sonic X-Treme, this engine felt quite a bit more similar to the way that later 3D Sonic game engines would eventually play. After moving back to the Boss engine, the team would significantly refine it compared to the single proof of concept build that is currently available to the public as of 2026. All of these later builds are currently Lost Media, aside from a few screenshots, magazine snippets and clips of gameplay at E3 96'.

- Unlike other Sonic X-Treme builds, Jade Gully Zone actually resembles a Gully.

- This engine was also going to implement bonus rounds known as "Sonic Pool", which apparently was based on/related to a special spherical rendering engine made separately. Only one screenshot exists of this round.
